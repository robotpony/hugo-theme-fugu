{{/* A page's first ```stack block, drawn for its build card (labels off, compact). Takes a dict: page, labels. Cards don't render the body, so this finds the block in .RawContent and reads it with hugo-warped's parse (partials/fence/parse.html), as formula-strip.html does. Outputs nothing when the page has none, or nothing to draw. It never warns: the page's own hook already has. */}} {{- with findRESubmatch "(?s)```stack[^\\n]*\\n(.*?)\\n```" .page.RawContent 1 }} {{- $p := partial "fence/parse.html" (dict "type" "stack" "inner" (index (index . 0) 1)) }} {{- if not $p.fallback }} {{- partial "stack/draw.html" (dict "parse" $p "labels" $.labels "compact" (not $.labels)) }} {{- end }} {{- end }}
