{{/* One line of a line-read fence body (```formula, ```stack), as the hook should read it: trimmed, with its note dropped. A note is a comment for whoever reads the source, `← why this is 2` (or `<- ...`) at the start of the line or after whitespace, to the end of the line; it's never drawn, nor in a drawing's alt text. `\←` and `\<-` are a literal arrow. A line that was only a note comes back empty, so callers skip it like a blank line. The rules are the shared fence spec's (hugo-warped, fences/README.md, "Notes"). Shared by render-codeblock-formula.html, formula-strip.html and stack/draw.html. Takes the raw line; returns a string. */}} {{- $line := replaceRE `(^|\s)(←|<-).*$` "" . }} {{- $line = replace (replace $line `\←` "←") `\<-` "<-" }} {{- return (trim $line " \t\r") }}
