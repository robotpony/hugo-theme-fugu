{{/* A principle tag: one whose own content/tags//_index.md says `principle: true`. Takes a tag name (as written in a page's `tags`, or a term page's slug) and returns a dict, or false when the tag isn't a principle: page the tag's term page essay the essay that explains it: the page named by the _index.md's `essay` (a content path, e.g. essays/reference-essays/win-the- fridge), else the first reference essay (params.fugu. referenceEssays) carrying the tag, else false short the chip's label on cards: the _index.md's `short`, else its title Shared by principle-chip.html, recipe-card.html and term.html.
