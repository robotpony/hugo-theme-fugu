{{/* Everything a blueprint holds, worked out once per blueprint and shared by its page, the methods list, the blueprint chip, and part navigation. A blueprint is a folder under a methods folder (blueprint/is.html, e.g. content/methods/burgers/_index.md); its parts are the pages in its parts/ folder and its builds the pages in builds/ (blueprint/of.html), whether those are plain folders or headless sections with an _index.md (the folder's lead, blueprint/lead.html), so it ranges over the blueprint's pages recursively. Takes the blueprint's section page (call it with partialCached, keyed by its path); returns a dict: page the blueprint's section page parts one dict per page in parts/, by weight, then date, then title: page, name (its title), n (1-based), and options (from its ## Options table, method/options.html) builds the pages in builds/: pinned ones (`pinned: true`) first, then those with an `era` (a year) oldest first, then the rest, each by weight, date, then title. The lineage sorts by era itself (blueprint/lineage-span.html), so a pinned build keeps its place in history there. */}} {{ $bp := . }} {{ $parts := slice }} {{ $dated := slice }} {{ $undated := slice }} {{ range $bp.RegularPagesRecursive.ByWeight }} {{ $page := . }} {{ with partial "blueprint/of.html" $page }} {{ if eq .role "part" }} {{ $parts = $parts | append (dict "page" $page "name" $page.Title "n" (add (len $parts) 1) "options" (partial "method/options.html" $page)) }} {{ else if eq .role "build" }} {{ if $page.Params.era }}{{ $dated = $dated | append $page }}{{ else }}{{ $undated = $undated | append $page }}{{ end }} {{ end }} {{ end }} {{ end }} {{/* sort is stable, so builds of the same era keep their weight order. */}} {{ $builds := (sort $dated "Params.era") | append $undated }} {{ $builds = (where $builds "Params.pinned" true) | append (where $builds "Params.pinned" "!=" true) }} {{ return dict "page" $bp "parts" $parts "builds" $builds }}
