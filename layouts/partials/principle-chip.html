{{/* Principle chip: one per principle tag the given page carries (a tag whose content/tags//_index.md says `principle: true`, see principle/term.html), nothing otherwise. Takes a dict: page (required), compact (bool: uses the tag's `short` label, e.g. "WTF", for the recipe card's tight top row; full pages use the tag's title, e.g. "Win the fridge"). Also carries the glossary popover (render-link.html's reference-essay branch): the chip is wrapped in the same .glossary-term/.glossary-pop markup as an inline [[Term]] mention of a reference essay, pulling its definition from the tag's essay, so hovering/focusing the tag itself explains the term without a trip to the tag page. The chip's own look (filled pill, not dotted underline) is unchanged — .glossary-link is not applied to the anchor, only the popover-reveal wrapper is reused. The extra .glossary-term-chip class (custom.css) flips the popover to open downward instead of the inline mechanism's default upward — the chip always sits near the top of a card or a page's tags row, with no room above it before colliding with the nav/hero. Compact (card) form adds .glossary-term-chip-compact on top of that: the popover's fixed 260px width is wider than a grid card, so left:0 let it bleed sideways into the next card. That variant drops its own positioning context (position: static) so the popover's containing block resolves up to .rcard-top instead (custom.css gives it position: relative for exactly this), and spans left:0/right:0 there — i.e. exactly the card's own width, however wide the grid happens to make it, instead of a hardcoded pixel value that assumes prose-width room. The full (tags-row) form keeps the original fixed-width popover since that context has plenty of spare width either side. */}} {{ $page := .page }} {{ $compact := .compact }} {{ $icon := `` }} {{ range $page.Params.tags }} {{ with partialCached "principle/term.html" . . }} {{ $label := cond $compact .short .page.Title }} {{ $essay := .essay }} {{ $def := "" }} {{ with $essay }} {{ $def = .Params.summary | default .Description }} {{ if not $def }} {{ $head := index (split .RawContent "\n## ") 0 | strings.TrimSpace }} {{ if and $head (not (hasPrefix $head "#")) }} {{ $def = index (split $head "\n\n") 0 }} {{ end }} {{ end }} {{ $def = $def | markdownify | plainify | htmlUnescape | truncate 200 }} {{ end }} {{ $chip := printf `%s%s` .page.RelPermalink ($icon | safeHTML) $label }} {{ if $def }} {{ $termClass := cond $compact "glossary-term glossary-term-chip glossary-term-chip-compact" "glossary-term glossary-term-chip" }} {{ $chip | safeHTML }}{{ .page.Title }}{{ $def }} {{ with $essay }}Read the full essay →{{ end }} {{ else }} {{ $chip | safeHTML }} {{ end }} {{ end }} {{ end }}
