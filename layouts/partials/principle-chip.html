{{/* Principle chip: one per principle tag the given page carries (a tag whose content/tags//_index.md says `principle: true`, see principle/term.html), nothing otherwise. Takes a dict: page (required), compact (bool: uses the tag's `short` label, e.g. "WTF", for the recipe card's tight top row; full pages use the tag's title, e.g. "Win the fridge"). Also carries a popover (the shared .pop-host/.pop component, see assets/js/popover.js) with the term's definition from the tag's essay, so hovering or focusing the chip explains it without a trip to the tag page. It opens downward, since the chip sits at the top of a card or a page's tags row. On a card (compact), .pop-card makes it span the card's top row instead of a fixed width, which would bleed into the next card. */}} {{ $page := .page }} {{ $compact := .compact }} {{ $icon := `` }} {{ range $page.Params.tags }} {{ with partialCached "principle/term.html" . . }} {{ $label := cond $compact .short .page.Title }} {{ $essay := .essay }} {{ $def := "" }} {{ with $essay }} {{ $def = .Params.summary | default .Description }} {{ if not $def }} {{ $head := index (split .RawContent "\n## ") 0 | strings.TrimSpace }} {{ if and $head (not (hasPrefix $head "#")) }} {{ $def = index (split $head "\n\n") 0 }} {{ end }} {{ end }} {{ $def = $def | markdownify | plainify | htmlUnescape | truncate 200 }} {{ end }} {{ $chip := printf `%s%s` .page.RelPermalink ($icon | safeHTML) $label }} {{ if $def }} {{ $chip | safeHTML }}{{ .page.Title }}{{ $def }}{{ with $essay }}Read the full essay{{ end }} {{ else }} {{ $chip | safeHTML }} {{ end }} {{ end }} {{ end }}
