{{- /* Wiki link render hook. Full override of themes/blowfish/layouts/ _default/_markup/render-link.html. _default/single.html rewrites [[Recipe Name]] to [Recipe Name]() before rendering — a link whose href is the page title (no scheme, no slash, no anchor). This hook catches those links, looks up the target page by title, and emits a proper Hugo URL. Every other link is written out as given. That differs from Blowfish's hook (Hugo's embedded one) in two ways: relative paths and #fragment links aren't resolved through GetPage or resources, and every http(s) link opens in a new tab, as an .extlink, whatever article.externalLinkForceNewTab says. Glossary popover: a [[Term]] that resolves to a glossary entry renders as a .glossary-link, going to the entry, with a hover/focus popover (partials/glossary/pop.html): a role="tooltip" holding the term and the entry's first sentence, tied to the link by aria-describedby, with no link inside. Entries come from hugo-warped's glossary partials (glossary/README.md): one file each in the glossary folder (params.fugu.glossaryPage in the reference section, by default content/reference/glossary/), plus the reference essays (where params.fugu.referenceEssays says; see section/reference-essay.html), entries with pages of their own (partials/glossary/args.html). The site's pages are tried first and the glossary second, so a reference essay is found as a page, then drawn as its entry, going to the essay. A [[Term]] that resolves to neither is a .broken-link, with a build warning, glossary [unresolved-mark]. Either tier is off when its param or section is "". A [[Title]] matches regular pages first, then section pages, so a blueprint (content/methods/burgers/_index.md) can be linked by its title too; a regular page wins when the two share one. */ -}} {{- $destination := .Destination -}} {{- $text := .Text | safeHTML -}} {{- $isWikiLink := and (not (strings.HasPrefix $destination "http")) (not (strings.HasPrefix $destination "/")) (not (strings.HasPrefix $destination "#")) (not (strings.HasPrefix $destination "mailto")) (not (strings.HasPrefix $destination "./")) (not (strings.HasPrefix $destination "../")) -}} {{- if $isWikiLink -}} {{- /* Normalize both sides before matching: lowercase, and collapse any run of non-alphanumeric characters (apostrophes, slashes, hyphens, ...) to a single space. This makes matching case-insensitive and punctuation- agnostic, so `[[rich veg mushroom stock]]` matches a title of "Rich veg/mushroom stock", and curly vs. straight apostrophes (content/recipes/chef-johns-hamburger-buns.md's title uses a curly ', a wiki link to it might be typed with a straight ') no longer matter — exact-match can't do either, so normalize by hand instead. */ -}} {{- $normDest := strings.TrimSpace (replaceRE `[^a-z0-9]+` " " (strings.ToLower $destination)) -}} {{- $matches := slice -}} {{- range site.RegularPages -}} {{- /* An entry file is a page with no URL of its own (its build options: render never): never a link target as a page. */ -}} {{- if not .RelPermalink }}{{ continue }}{{ end -}} {{- $normTitle := strings.TrimSpace (replaceRE `[^a-z0-9]+` " " (strings.ToLower .Title)) -}} {{- if eq $normTitle $normDest -}} {{- $matches = $matches | append . -}} {{- end -}} {{- end -}} {{- if not $matches -}} {{- range where site.Pages "Kind" "section" -}} {{- $normTitle := strings.TrimSpace (replaceRE `[^a-z0-9]+` " " (strings.ToLower .Title)) -}} {{- if eq $normTitle $normDest -}} {{- $matches = $matches | append . -}} {{- end -}} {{- end -}} {{- end -}} {{- $args := partialCached "glossary/args.html" "args" -}} {{- if gt (len $matches) 0 -}} {{- $target := index $matches 0 -}} {{- $entry := false -}} {{- if and $args (partial "section/reference-essay.html" $target) -}} {{- range partial "hugo-warped/glossary/entries.html" $args -}} {{- if eq .url $target.RelPermalink }}{{ $entry = . }}{{ break }}{{ end -}} {{- end -}} {{- end -}} {{- with $entry -}} {{- partial "glossary/pop.html" (dict "page" $.Page "entry" . "text" $text) -}} {{- else -}} {{ $text }} {{- end -}} {{- else -}} {{- $entry := false -}} {{- with $args -}} {{- $entry = partial "hugo-warped/glossary/resolve.html" (merge . (dict "target" $destination)) -}} {{- end -}} {{- with $entry -}} {{- partial "glossary/pop.html" (dict "page" $.Page "entry" . "text" $text) -}} {{- else -}} {{- warnf "glossary [unresolved-mark]: %q in %q" $destination (cond (not $.Page.File) $.Page.Path $.Page.File.Path) -}} {{ $text }} {{- end -}} {{- end -}} {{- else -}} {{- $isExternal := strings.HasPrefix $destination "http" -}} {{ $text }} {{- end -}}
