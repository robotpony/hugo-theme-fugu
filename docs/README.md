# Fugu docs

- [getting-started.md](getting-started.md): from an empty Hugo site to one working recipe page.
- [recipe-format.md](recipe-format.md): how a recipe is written: sections, multi-component recipes, wiki links, formula, stack and flow diagrams, photos.
- [frontmatter.md](frontmatter.md): every frontmatter field Fugu reads, and what it changes on the page.
- [configuration.md](configuration.md): every `[params.fugu]` setting, the optional sections, and the Blowfish settings that matter.
- [customizing.md](customizing.md): making it look like your site: the `--fugu-*` colour and type properties, the `fugu` scheme, fonts (self-hosted too), overriding a rule or a template, and the icon kits.
- [essay-format.md](essay-format.md): writing an essay: frontmatter, folders as formats, the reading sidebar, the sections that move, and a suggested house style.
- [blowfish.md](blowfish.md): the Blowfish version Fugu is tested against, the Blowfish files it replaces and why, the Blowfish settings that work differently, and moving to a new Blowfish.
- [tools.md](tools.md): the command-line tools for a site's content and for theme work, the tests, and editing `content/` as an Obsidian vault.
- [features.md](features.md): what Fugu adds, as a reader sees it: the recipe sidebar, check-off, scaling and units, formula and stack diagrams, wiki links and the glossary, cards, pinned pages, principle tags, methods and blueprints, drafts, search, and the recipe index.
- [design/class-inventory.md](design/class-inventory.md): working notes for PLAN.md §5, every class Fugu emits, the Not a Chef rules that style it, and whether each is structure or look.
